# Voice Agent (Python)

## Features

- Email summarization
- Calendar overview
- Voice-ready architecture

## Setup

```bash
git clone https://github.com/your-username/voice-agent-python.git
cd voice-agent-python

python -m venv venv
source venv/bin/activate  # macOS/Linux
pip install -r requirements.txt
cp .env.example .env
```
